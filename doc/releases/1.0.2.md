# 1.0.2

ThinkRail Launcher Lite 首个公开安装包版本，版本号与 Antigravity Launcher Lite 对齐。两项目保持独立应用标识、配置目录和客户端身份校验。

- 设置页新增启动器更新入口，显示版本、发布说明与下载进度。
- 支持下载签名更新包，校验通过后自动安装并重启启动器。
- 支持直连或显式使用启动页配置的代理，不更改系统代理。
- 更新启动器时保留配置，不退出或重启 ThinkRail。

## 下载与验证范围

- macOS arm64 / Intel x64：DMG、应用 ZIP，以及用于应用内更新的签名 `.app.tar.gz`。
- Windows x64：当前用户 NSIS 安装器及更新签名。
- Linux x64：deb、AppImage；AppImage 提供更新签名。
- 附带 `latest.json`、`BUILD-METADATA.json`、`SHA256SUMS.txt`。更新清单和全部发布附件均包含校验值。

四个架构均已通过版本与架构检查、安装包结构与短时启动烟测，全部附件、构建提交和 SHA-256 已核对。CI 检查不等同于真实设备完整使用验收，也不等同于真实 ThinkRail 对话验证。

本机 macOS Apple Silicon 已从 0.1.1 测试版通过应用内检查发现正式版，完成下载、签名校验、自动替换和重启；重启后版本为 1.0.2，二进制与 CI 正式包一致，默认路径、代理和开关正常恢复。本机升级前未生成配置文件，因此尚未验证已有配置文件的字节保留；配置持久化兼容另有 Rust 用例覆盖。Windows/Linux 与 Intel Mac 的真实设备升级仍待验收。Linux 应用内更新当前提供 AppImage 格式，deb 用户通过包管理方式更新。

0.1.0 未内置更新模块，需要先安装一次此版本，后续即可在应用内更新。macOS 运行在只读磁盘映像或无写入权限的目录时，请先将应用移至可写的应用目录。macOS 更新签名用于验证更新来源，不等同于 Apple Developer ID 签名或公证。

Windows / Linux 的真实设备安装升级仍需验收。
